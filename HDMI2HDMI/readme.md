


## モジュール構成
モジュール役割 dvi_frame_buffer_topトップ。全IPのポートを束ねる  
image_composer 出力タイミング生成＋レイヤー合成  
font_rom_lathe "Lathe"文字列のビットマップROM  

gen_font_rom.py フォントROM生成スクリプト本体  
lathe_font.hexVerilog $readmemh用HEXファイル（100行×80桁）  
lathe_font_inv.png 視覚確認用PNG（黒文字/白背景、3倍拡大）

## HEXファイル仕様
項目値行数100行（= TXT_H）  
1行の幅80桁 = 320ビット（= TXT_W）  
ビット順MSB = x=0（左端）、LSB = x=319（右端）  
フォントDejaVuSans-Bold 90pt  
描画結果286×69px、中央配置  
ラウンドトリップ検証✅ 完全一致
