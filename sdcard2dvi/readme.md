# sdcard2dvi

SD カードに保存した画像を読み出し、DVI(HDMI) へ出力する FPGA プロジェクト。

## ボード
- Tang Mega 138K Pro Dock
- Device: GW5AST-LV138FPG676AC1/I0 (GW5AST-138B)

## 目標
1. SD カード (SPI モード) から画像データを読み出す
2. 読み出した画像をフレームバッファに展開する
3. DVI TX で 1280x720@60Hz 出力する

## モジュール構成 (予定)

```
┌──────────────────────────────────────────────────┐
│                      top                          │
│                                                   │
│  ┌────────┐   ┌─────────────┐   ┌─────────────┐  │
│  │ SD SPI │──▶│ Image Buffer│──▶│  DVI TX     │  │
│  │  reader │   │ (読み出し)  │   │ (出力)      │  │
│  └────────┘   └─────────────┘   └─────────────┘  │
│                                                   │
│  ┌──────────────────────────────┐                │
│  │  Clock Generator (PLL)       │                │
│  │  clk_pix(74.25M) / clk_5x    │                │
│  └──────────────────────────────┘                │
└──────────────────────────────────────────────────┘
```

## クロック
- システムクロック: 50 MHz
- ピクセルクロック: 74.25 MHz (1280x720@60Hz)
- シリアルクロック: 371.25 MHz (DVI 5x)
